# KMK Engineering Website — Windows Local Copy

## Easiest way
1. Install Node.js LTS (Node 20+).
2. Double-click `RUN_KMK_WEBSITE.cmd`.
3. On first run it installs packages automatically.
4. When Vite shows `Local: http://localhost:5173/`, open that address in Chrome.

## Terminal method
```powershell
npm install
npm run dev
```
